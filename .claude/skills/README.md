# Marketing-site copy skills

Selected from [coreyhaines31/marketingskills](https://github.com/coreyhaines31/marketingskills), commit `5b2c0007766c6a1cf1d53fd8fc73e979e0821022`.
Installed locally to this repository; skill files and their references are unmodified upstream copies.

- `product-marketing`: Establish product positioning, audience, and brand voice in `.agents/product-marketing.md`.
- `copywriting`: Draft homepage, landing-page, feature, and CTA copy.
- `copy-editing`: Improve clarity, tone, specificity, and supporting evidence.
- `cro`: Review page messaging, section hierarchy, objections, and calls to action.

Start with product-marketing to establish shared context, then use copywriting and copy-editing for drafts. Use cro when reviewing the overall page.

Only these four skills are installed. Other skills mentioned in their Related Skills sections are optional and are not bundled here.
